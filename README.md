# 📚 EduTrack AI

O **EduTrack AI** é uma aplicação web desenvolvida em **Python** com **Streamlit**, integrada ao **Xano**, para auxiliar estudantes no gerenciamento de disciplinas, tarefas e acompanhamento do desempenho acadêmico por meio de dashboards interativos.

## 🚀 Funcionalidades

* 🔐 Login de usuários
* 📚 Gerenciamento de disciplinas
* ✅ Controle de tarefas
* 📊 Dashboard com métricas e gráficos
* 🔎 Filtros por disciplina e status
* 📄 Geração de relatórios

## 🛠 Tecnologias

* Python
* Streamlit
* Pandas
* Xano (API e banco de dados)

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/edutrack-ai.git
```

2. Instale as dependências:

```bash
pip install -r requirements.txt
```

3. Execute a aplicação:

```bash
streamlit run app.py
```

## 📌 Objetivo

Facilitar a organização da rotina de estudos, permitindo que estudantes acompanhem suas disciplinas, tarefas e progresso de forma simples, intuitiva e visual.
